# Ballu Syncleo для Homebridge

Русский · [English](README.md)

Плагин для локального управления бризером Ballu ONEAIR ASP-100 из Homebridge. Он обнаруживает бризер через mDNS и обменивается командами Syncleo по UDP. Проверено на ASP-100 с прошивкой Wi-Fi-модуля 1.38 и Homebridge 2.5.0 на ARMv7.

- Включение, выключение и выбор одной из семи скоростей.
- CO₂ в ppm на устройствах, которые передают эти показания. Для признака повышенного CO₂ в HomeKit задан порог 1000 ppm.
- Версия прошивки Wi-Fi-модуля и его MAC-адрес в сведениях об аксессуаре. MAC отображается в поле серийного номера HomeKit.
- Настройка нескольких бризеров через интерфейс на русском или английском.

## Установка из исходников

Для сборки нужен Node.js 22.12+ или 24.x. Выполните команды в клоне репозитория.

```sh
npm ci
npm pack
```

Установите полученный архив в каталог npm, который использует ваш Homebridge. Для глобальной установки Homebridge выполните `npm install -g ./homebridge-ballu-syncleo-0.1.4.tgz`. Для официального Docker-образа скопируйте архив в примонтированную папку данных Homebridge и выполните `npm install ./homebridge-ballu-syncleo-0.1.4.tgz` из этой папки внутри контейнера.

## Настройка

1. В HOMMYN откройте настройки бризера, выберите **Управление доступом → Поделиться** и скопируйте ссылку целиком.
2. В Homebridge откройте **Плагины → Ballu Syncleo → Конфигурация плагина**. Добавьте бризер, задайте имя и вставьте ссылку.
3. Сохраните настройки и один раз перезапустите Homebridge для загрузки платформы. Дальнейшие добавления и изменения применяются при работающей платформе.

Homebridge должен видеть объявления mDNS бризера и обмениваться с ним UDP-пакетами по локальной сети. В Docker на Linux для этого можно использовать сеть хоста. Ссылка HOMMYN содержит токен управления. Homebridge хранит её в конфигурации и резервных копиях. Удаляйте ссылку из материалов, которые прикладываете к отчётам об ошибках.

## Разработка

Для сборки выполните `npm ci` и `npm run build`. Команда `npm pack --dry-run` покажет список файлов установочного архива.

Реализация Syncleo опирается на [описание протокола ASP-100](https://github.com/opensolutionshobby/asp-100-home-assistant/blob/main/PROTOCOL.md). Плагин поддерживается независимо. Условия использования приведены в [LICENSE](LICENSE).
